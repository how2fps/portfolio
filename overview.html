SproutTeach

01

Interactive teaching platform · Frontend & backend

A classroom platform for creating quizzes, running live lessons and reviewing student understanding. Teachers can annotate a shared whiteboard and revisit session reports; students join with a room code.

Frontend source ↗ Backend source ↗
Technology & app screenshots

Frontend

React and TypeScript, built with Vite, power the teacher and student views. Tailwind CSS and Radix UI provide the interface components. TanStack Query and Axios manage API data; React Hook Form and Zod handle quiz forms. Konva supports whiteboard drawing, dnd-kit reorders questions, Socket.IO receives live updates, and jsPDF exports reports.

  • React
  • TypeScript
  • Vite
  • Tailwind CSS
  • TanStack Query
  • Konva

Backend

Node.js, Express and TypeScript provide the API. MySQL stores users, quizzes and session history. Redis holds live room state and login sessions, with Lua scripts for atomic quiz updates. Socket.IO and Redis Pub/Sub deliver classroom events. Passport supports Google and Microsoft sign-in; images upload to Cloudflare R2 through the AWS S3 SDK. Docker packages the backend.

  • Node.js
  • Express
  • MySQL
  • Redis
  • Lua
  • Socket.IO
  • Passport
  • Cloudflare R2
  • Docker

Envorya POS

03

Envogue · Full-stack spa POS

Envogue is a multi-branch point-of-sale and operations platform for spa, wellness and TCM businesses. It brings appointments, customer packages and credit, sales, inventory and reporting into one app, with separate staff, customer and management workflows.

Explore product ↗
Technology & app screenshots

Frontend

React and TypeScript power the POS, booking and customer screens, with Vite for development and PWA packaging. React Router organises the different workflows. Tailwind CSS, Flowbite and Material UI provide interface components; i18next supports English and Chinese. Axios handles API requests, Chart.js visualises reports, and jsPDF and spreadsheet exports support record sharing. ZXing enables QR scanning.

  • React
  • TypeScript
  • Vite
  • Tailwind CSS
  • Material UI
  • i18next
  • Chart.js
  • PWA

Backend

A Node.js and Express API, written in JavaScript, manages branch operations and business rules. MongoDB stores records; shared payment calculations, transactions and retry protection support packages, store credit and refunds. JWT, bcrypt and branch-scoped permissions separate staff, owner and customer access. Firebase Storage handles images, Pusher delivers live updates, and Mailjet sends verification emails and receipts. Vercel hosts the API and scheduled maintenance routes.

  • Node.js
  • JavaScript
  • Express
  • MongoDB
  • JWT
  • Firebase Storage
  • Pusher
  • Mailjet
  • Vercel
